About Clocked EDI Engine

Clocked EDI Engine is a modern, secure X12 EDI transaction processing engine built for enterprise-grade electronic data interchange.

🔒

PII Protection

Automatic detection and redaction of personally identifiable information before processing.

🛡️

Injection Guard

Real-time prompt injection detection to block malicious payloads and injection attacks.

⚡

Clocked Extract + Decide

AI-powered structured field extraction and processing readiness assessment.

📋

X12 Support

Support for 810 (Invoice), 850 (Purchase Order), 856 (Advance Ship Notice), and 820 (Payment Order) transaction sets.

Clocked API References

Base URL

https://your-domain.com

Endpoints

GET
/health
Check the health and operating mode of the EDI engine backend.
Response: 200 application/json 
{ "mode": "mock | live", "status": "ok" }
POST
/api/edi/process
Process an X12 EDI transaction through the full pipeline: parse, validate, secure, extract, decide, serve.
Content-Type: multipart/form-data Response: 200

Request

FormData:
  edi: "ISA*00*...*IEA*1*...*~"

Response

{ "requestId": "...", "transactionType": "810", "status": "processed", "blocked": false, ... }

Response Fields

FieldTypeDescription
requestIdstringUnique transaction identifier
transactionTypestringX12 transaction set (e.g., 810, 850)
statusstringProcessing outcome (processed, blocked_injection, security_check_failed)
blockedbooleanWhether the transaction was blocked
securityobjectPII Protection and Injection Guard results
structuralobjectX12 envelope validation results
normalizedobjectMapped X12 segments to structured JSON
clockedobjectExtract + Decide AI processing results

Status Codes

CodeMeaning
